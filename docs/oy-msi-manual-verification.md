# OY_MSI(학교 밖 청소년 마음상태검사) 수동 검증 체크리스트

Task 19(1단계 완료 확인) Step 4는 브라우저에서 사람이 직접 눈으로 봐야 하는 항목이라 자동화 에이전트가
대신 실행할 수 없다. 이 문서는 그 10개 시나리오를 실제로 손으로 따라 할 수 있게 클릭 경로까지 풀어 쓴 것이다.

이 문서 자체는 Task 19의 산출물이며, 아래 체크박스는 **아직 아무도 체크하지 않은 상태**다. 검증한 사람이
직접 체크하고 "확인 결과" 칸에 날짜·현상을 적는다.

---

## 0. 로컬 실행 준비

### 0.1 서버 기동
```bash
cd "C:\work\심지\simji"
export PATH="/c/xampp/php:$PATH"
php artisan serve
```
브라우저에서 `http://127.0.0.1:8000` 접속.

### 0.2 DB 시딩 (아직 안 했다면)
```bash
export PATH="/c/xampp/php:$PATH"
php artisan migrate:fresh --seed
```
`OY_MSI` 검사, 채점 규칙, 문안 174건, 그리고 로그인용 계정 `test@example.com`이 함께 만들어진다.

### 0.3 테스트 계정
시더가 이미 다음 계정을 만들어 둔다(추가 작업 불필요):
- 이메일: `test@example.com`
- 비밀번호: `password`

로그인 페이지: `http://127.0.0.1:8000/login`

개인 경로 시나리오 대부분은 이 계정으로 로그인해서 진행한다. **단, 같은 브라우저 세션으로 다른 나이(만
13세 vs 만 16세)를 다시 테스트하려면 로그아웃 후 다시 로그인하거나 시크릿창을 새로 열어야 한다** — 연령은
세션(`oymsi_age:OY_MSI`)에 한 번 담기면 재확인 없이 통과되기 때문이다.

### 0.4 검사 페이지 진입
`OY_MSI`는 `status=draft`라 `/tests` 카탈로그 목록·검사방 목록에는 안 뜬다(카탈로그 방 목록은
`status='active'`만 보여줌). 하지만 상세 페이지는 상태 필터가 없으므로 **주소창에 직접 입력**하면 된다.

```
http://127.0.0.1:8000/tests/OY_MSI
```

여기서 로그인한 상태로 "직접 응시하기" 카드의 **검사 시작** 버튼을 누르면 개인 경로가 시작된다.
"여러 명에게 발급하기" 카드의 **검사권 발급** 버튼을 누르면 링크(기관) 경로가 시작된다(무료 검사라
검사권이 없어도 발급된다).

## 1. 시나리오 체크리스트

각 항목은 **경로(URL) → 클릭/입력 → 확인**의 순서로 적었다. 실제 라우트 이름은
`routes/web.php`에서 그대로 옮겼다(추측 없음):
`assessment.consent`, `oymsi.age.form/submit`, `oymsi.profile.form/submit`, `assessment.intro`,
`assessment.start`, `assessment.take/submit`, `result.show`, `oymsi.share.form/create/revoke`,
`oymsi.share.view`(`/r/{token}`), `link.age.form/submit`, `link.landing/start/take/submit`(`/t/{token}`).

문항 번호(생년월일 힌트 포함, 오늘 2026-07-28 기준):
- 만 16세로 통과하려면 생년월일 예: `2010-01-15`
- 만 13세로 걸리게 하려면 생년월일 예: `2013-01-15`
- SAF 문항 번호(60문항 중): SAF01=10번, SAF02=18번, SAF03=26번, SAF04=34번, SAF05=42번, SAF06=60번.
  (SAF01~04는 "전혀 없었다/한두 번 있었다/여러 번 있었다/자주 있었거나 지금도 그렇다" 4지선다,
  SAF05·06은 "없었다/1회/2~3회/4회 이상" 4지선다. 화면에는 4열 그리드로 나온다.)

## 2. 브라우저에서만 확인 가능한 항목 (전 태스크에서 "시각 검증 미실시"로 남은 것들)

아래는 코드 리뷰나 자동화 테스트로는 검증되지 않고, 실제 화면에서 눈으로만 확인 가능한 항목이다.
위 시나리오를 진행하면서 아래 표에도 체크한다.

| 항목 | 어디서 | 확인할 것 | 체크 |
|---|---|---|---|
| 안전 안내 모달 표시 | `assessment.take` 화면, SAF 문항 응답 시 | 모달이 실제로 화면 중앙에 반투명 배경과 함께 뜨는가(`#safety-modal`의 `hidden`↔`flex` 전환이 실제로 눈에 보이는가) | [ ] |
| 4열 그리드 | `assessment.take` 화면, OY_MSI 4점 척도 문항 | 좁은 화면(모바일 폭)에서도 보기 4개가 한 줄에 배치되고 글자가 깨지지 않는가(`grid grid-cols-4`) | [ ] |
| 복사 버튼 | `oymsi.share-created`(공유 링크 생성 직후) | "링크 복사하기" 버튼을 눌렀을 때 실제로 클립보드에 복사되고 "복사했어" 문구가 나타나는가 | [ ] |
| 인쇄 레이아웃 | `result.show`(청소년 결과 화면) 우측 하단 "인쇄하기" 버튼 | 브라우저 인쇄 미리보기에서 `print:hidden` 처리된 버튼들이 실제로 안 보이고, 나머지 결과 내용이 페이지 경계에서 잘리지 않는가 | [ ] |
| `tel:` 링크 | 안전 모달, age-blocked, share-form 등 109/1388/112/119 전화번호 | 모바일 브라우저에서 탭했을 때 전화 앱 다이얼로 실제 연결되는가(PC에서는 시뮬레이션 불가 — 반드시 모바일 기기로 확인) | [ ] |
