# 심지 플랫폼 — 부분 구현 4종 설계

- 작성일: 2026-06-26
- 범위: 개발안(`simji심지플랫폼_개발(안).hwpx`) 대비 "부분 구현(⚠️)" 상태였던 항목을 흐름/화면 수준까지 완성
- 비범위: 실제 검사 문항(임상), 결제, 관리자 통계, 기관 문의폼, 채점엔진 변경

## 배경

현재 1차 오픈 핵심 검사 파이프라인(메인·카드·실시·결과·채점)은 동작하나, 다음이 미완:
- 연령방이 3개(대학생·직장인·실버)만 존재 — 개발안의 초등·중고등 2개 누락
- 방별 검사 콘텐츠는 직장인 샘플 1종뿐
- 보호자(법정대리인) 동의 흐름 없음
- 강의·코칭 페이지는 coming-soon 스텁

이번 작업은 **"흐름/화면만"** 완성한다. 실제 검사 콘텐츠는 0종 유지(준비중 카드).

## 확정된 결정 사항

1. **검사 콘텐츠**: 실제 문항 작성 안 함. 방별 검사는 개발안 §4 검사명을 **"준비중" 빈 카드**로만 노출(응시 불가). 추후 단디 포팅 시 실제 검사로 교체.
2. **보호자 동의**: 검사 속성(`requires_guardian_consent` 플래그)으로 판정. 화면/흐름만 구현. 실제 아동 검사가 없으므로 평소엔 발동 대상 없음 — 인프라로만 존재. 개발 검증은 기존 샘플에 플래그를 잠깐 켜서 확인 후 되돌림.
3. **신고의무 고지 문구**: 보호자 동의 화면에 **임시 문구**로 포함. 구체 내용·법무 검토는 추후 협의(placeholder임을 주석으로 명시).
4. **강의·코칭**: 개발안 §8 기반 **정적** 소개 페이지. 신청 기능은 2차.

### 향후 협의 과제(이번 비범위, 의식만)
- 학대·고위험 스크리닝 검사는 **기관(학교·상담센터) 주관**을 기본으로 → 부모 동의권자=가해자 딜레마 회피. 신고의무자 연계.
- 검사 속성에 `고위험스크리닝`/`기관전용` 플래그 추가 여지 (이번엔 컬럼 추가 안 함, YAGNI).
- 만 14세 이상 본인 동의 / 결제 시 만 19세 미만 이슈는 결제 도입 시점에.
- **[하드 선결조건] 보호자 동의 서버 강제**: 현재 `agree`는 동의 검증 후 리다이렉트만 하고 상태를 저장하지 않아, `start()`를 직접 호출하면 동의를 건너뛸 수 있다(어른 검사와 동일한 기존 패턴). 활성 아동 검사가 0종이라 지금은 도달 불가 → 비범위. **단, 실제 만14세미만/고위험 검사를 `status=active`로 올리기 전에 반드시** 동의 상태를 attempt/세션에 영속화하고 `start()`에서 미동의 시 차단하도록 막아야 함(법적 동의가 우회 가능한 체크박스로 남으면 안 됨). (2026-06-26 최종 리뷰 지적)

## 작업 항목

### A. 5개 연령방 완성
- `app/Support/Rooms.php`: `elem`(초등학생), `middle`(중고등학생) 2개 추가. 순서는 초등→중고등→대학생→직장인→실버.
  - 각 방에 `desc`, `tags`(개발안 §4 고민 키워드) 채움.
- 방 이미지: `public/images/rooms/elem.png`, `middle.png`.
  - `scripts/gen-images.php`에 두 job 추가. API 키 있으면 생성, 없으면 **CSS 그라데이션/일러스트 플레이스홀더**로 폴백(뷰가 이미지 없을 때 깨지지 않도록).
- 홈 카피 보정(`resources/views/home.blade.php`): "대학생부터 실버" → "초등학생부터 실버까지". 가치밴드 desc도 동일.
- 홈/카탈로그는 `Rooms::all()` 배열 기반이라 방 추가는 자동 전파(그리드만 3→5열 대응 확인).

### B. 방별 "준비중" 검사 카드
- 방마다 **계획된 검사 목록**(개발안 §4 검사명)을 정적 데이터로 정의. 위치: `Rooms.php`의 각 방에 `planned_tests` 배열(이름 + 대상 + `guardian` 여부 표시용).
- `resources/views/catalog/room.blade.php`: 활성(DB) 검사 카드 렌더 후, 그 아래 **"준비중" 비활성 카드**(회색, 클릭 불가, "준비중" 뱃지) 렌더.
  - 초등방 준비중 카드에는 "보호자 동의 필요" 뱃지 표시.
- 활성 검사가 들어오면 해당 카드만 자동으로 정상 카드로 승격(별도 작업 불필요).
- 빈 방 안내 문구(`준비 중인 검사입니다`)는 준비중 카드가 채우므로 활성+계획 모두 비었을 때만 노출.
