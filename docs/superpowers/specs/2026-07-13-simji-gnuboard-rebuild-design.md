# 심지 그누보드 재구축 — 설계 (Design)

- 작성일: 2026-07-13
- 상태: 합의 완료 (구현 순서까지 확정, 단계별 상세 spec은 각 단계 착수 시 별도 작성)

---

## 1. 배경 / 왜 바꾸나

현재 심지는 **Laravel 12**로 만들어져 있고 Render에 프리뷰가 떠 있다. 실운영을 위해 카페24에 올리려 했으나:

- 보유한 카페24 호스팅은 **공유 웹호스팅(10G 광 아우토반, PHP 7.4)** 3개이며 전부 사용 중.
- Laravel 12는 **PHP 8.2 필수** → 현재 공유호스팅에서 못 돌린다. PHP 버전 변경 옵션도 안 보임.
- Laravel을 돌리려면 **가상서버(월 비용)** 가 필요.
- 반면 **다른 프로젝트(단디 등)가 전부 그누보드**라 스택이 통일돼 있고, 심지만 Laravel로 두면 운영·배포·유지보수가 이원화된다.
- 심지의 핵심인 **검사 채점 엔진(규준표·T점수·백분위·PDF)이 이미 단디(그누보드)에 존재**한다.

### 결정
심지를 **그누보드로 재구축**한다. 공유호스팅에 그대로 올라가고(추가 서버비 0원), 스택이 단디와 통일되며, 검사 엔진을 재활용할 수 있다.

---

## 2. 핵심 결정 사항

| 항목 | 결정 |
|---|---|
| 기존 Laravel 심지 | **보존.** 삭제·수정하지 않고 "화면·흐름 설계도(참고본)"로 사용 |
| 작업 위치 | **새 폴더** 하나 생성 후 거기서 그누보드로 신규 구축 |
| 베이스 | **그누보드5** (호스팅 PHP 7.4 호환, 단디와 계열 통일) |
| 검사 채점 엔진 | **단디의 기존 그누보드 코드 재활용(A안)**. 단, **구현 순서상 나중(5단계)** |
| 호스팅 | 카페24 **웹호스팅 신규 1개 추가**(기존 3개 다 사용 중이라 4번째 아이디 신설) |
| 도메인 | `simji.org` (구매 완료, host.kr 등록) → 새 호스팅에 A레코드 연결 |
| 완성 기준 | 현재 Laravel 심지의 **화면·기능을 빠짐없이** 그누보드 버전에 반영 |

### 명시적으로 아닌 것 (오해 방지)
- 단디 운영 사이트를 건드리는 것이 **아니다** (엔진은 코드 참고·재활용일 뿐, 원본 무관).
- Laravel→그누보드 **자동 변환이 아니다.** 구조가 완전히 달라 **재구현**이다. Laravel 심지는 참고용 설계도.

## 3. 반영 대상 — 현재 심지(Laravel) 화면·기능 인벤토리

"빠짐없이"의 기준 체크리스트. 그누보드 버전이 최종적으로 이 전부를 커버해야 한다.

### 공개 페이지
- 홈 (`/`)
- 검사 목록 (`/tests`)
- 연령방 / 마음의 방 (`/tests/room/{code}`)
- 검사 상세 (`/tests/{code}`)
- 강의·코칭 (`/coaching`)
- (목업 — 화면만, 백엔드 미연결) 기관·단체 / 리포트샘플 / 전문가 / 심지소개 / 고객센터

### 회원 / 인증
- 회원가입 **선택화면 + 개인가입 + 기관가입**
- 로그인 / 비밀번호 찾기·재설정 / 이메일 인증 / 비밀번호 확인
- **카카오 소셜 로그인** (redirect + callback)
- 프로필 (수정 / 비밀번호 변경 / 회원 탈퇴)

### 검사 (로그인 필수)
- 보호자 동의 → 인트로 → 응시(문항) → 채점 → 결과
- 결과: **신호등 요약 + 정밀 프로파일**, 채점 대기(pending) 상태 포함

### 검사권 링크 응시 (비로그인)
- 링크 랜딩 (`/t/{token}`) → 응시 → 완료

### 내 검사함 (로그인)
- 발급 검사 **명부·결과 관리** (열람 승인/대기)
- 검사권 발급(issue) / 결과 공개 토글

### 결제
- 체크아웃 → PG return → 완료 / 실패

### 관리자
- 대시보드 · 회원 · 주문 · 검사
- (현재 인증 가드 없음 → 그누보드에선 관리자 권한으로 보호)

### 데이터 모델 (참고)
tests / test_items / test_attempts / attempt_answers / test_results / scoring_rules / products / orders / order_items / payments / vouchers / users(가입·유형·링크 필드)

## 4. 아키텍처 원칙

- **그누보드 기본 활용**: 회원·로그인·비번찾기·프로필·관리자 뼈대·소셜로그인은 그누보드가 제공하는 것을 **심지에 맞게 커스터마이즈**한다. 새로 만들지 않는다.
- **심지 고유 기능은 직접 구현**: 연령방, 검사 흐름, 검사권 링크 응시, 결과지 — 단디 방식(커스텀 테이블 + 부가기능 PHP)을 참고해 구축.
- **검사 데이터**는 그누보드 게시판이 아니라 **커스텀 테이블**로 모델링(단디 구조 참고).
- 각 화면/기능 단위는 목적이 하나로 명확하도록 분리한다.

## 5. 구현 순서 (로드맵)

각 단계는 착수 시점에 별도 상세 spec → plan → 구현 사이클을 돈다.

| 단계 | 내용 | 비고 |
|---|---|---|
| **0. 기반 세팅** | 새 폴더 + 그누보드5 설치, 심지 스킨 뼈대(공통 헤더/푸터·브랜드 색·로고·레이아웃) | 먼저 |
| **1. 회원/인증** | 가입 선택화면(개인/기관)+유형별 폼, 로그인, 비번찾기, 프로필, **카카오 로그인** | 그누보드 기본 + 커스터마이즈 |
| **2. 공개·소개 화면** | 홈 / 심지소개 / 기관·단체 / 전문가 / 고객센터 / 리포트샘플 / 강의·코칭 | 대부분 정적, 빠름 |
| **3. 검사 구조** | 마음의 방(연령방) → 검사목록 → 검사상세, 검사 데이터 구조 설계 | 커스텀 테이블 |
| **4. 검사 응시 흐름** | 보호자동의 → 인트로 → 문항 응시 → 답 저장 (결과는 자리만) | 채점 전까지 |
| **5. ★검사 채점 엔진** | 규준표·T점수·백분위 → 신호등+정밀 프로파일 → PDF 결과지 | **단디 재활용, 조금 나중** |
| **6. 검사권 링크 응시** | 링크 발급 → 대상자 비로그인 응시 → 명부 결과관리(승인/대기) | |
| **7. 결제** | 검사권 상품 → 체크아웃 → PG → 주문 | 영카트 vs 커스텀은 착수 시 결정 |
| **8. 관리자** | 대시보드·회원·주문·검사 (관리자 권한 보호) | |

핵심: **0~4단계로 화면·흐름을 먼저 세우고 → 5단계에서 단디 검사 엔진을 붙이고 → 6~8 마무리.**

## 6. 나중에 정할 것 (미결 / Open questions)

- 카페24 웹호스팅 신규 1개 추가 (플랜·용량·PHP 버전 확정) 및 `simji.org` A레코드 연결.
- 단디 소스 코드 로컬/서버 접근 확보 (5단계 엔진 재활용 전 선결).
- 결제 방식: 그누보드 **영카트** 활용 vs 검사권용 **커스텀 결제** (7단계 착수 시 결정).
- 검사 라인업 확정(방별 실제 검사 종류·순서), 보호자 동의 필수 대상 검사 범위.
- 유료 판매 필수 법적 정보(사업자등록·통신판매신고·약관·개인정보처리방침·환불규정).
