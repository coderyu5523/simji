# 심지(simji) 현재 사이트 — 협의용 정리

작성 2026-07-02. **지금 만들어져 있는 사이트를 그대로** 정리한 문서입니다.
무엇이 이미 되어 있고, 무엇이 아직 화면만 있는 상태인지 한눈에 보고 다음 방향을 정하기 위한 자료입니다.

> **한 줄 요약**
> 검사를 고르고 → 응시하고 → 신호등 결과를 받고 → 결제까지 하는 **핵심 흐름은 실제로 작동**합니다.
> 다만 **검사 종류(콘텐츠)와 소개 페이지들은 아직 샘플/예시** 수준입니다.
> "기계는 돌아가는데, 안에 넣을 검사 내용과 바깥 소개 페이지가 아직 비어 있는" 상태입니다.

---

## 1. 사이트가 지향하는 것

**"마음을 검사하고, 삶을 코칭하다"** — 전 생애(초등생 ~ 실버 세대) 마음건강 플랫폼.

- 연령별 **'마음의 방'** 으로 나눠, 복잡한 검사 목록 대신 나에게 맞는 방부터 고름
- 결과는 전문용어 대신 **초록·노랑·빨강 신호등** 리포트로 쉽게
- 검사에서 끝나지 않고 **결과 이후 강의·코칭으로 연결**
- 개인뿐 아니라 **학교·기업·복지관 등 기관 단체 도입**을 주요 고객으로

## 2. 상단 메뉴(네브바) — 각 탭이 하는 일

| 탭 | 역할 | 현재 상태 |
|---|---|---|
| **심지소개** | 브랜드 스토리 — "검사 사이트를 넘어 마음성장 플랫폼" 소개 | 🟡 소개 화면만 |
| **심리검사** | **핵심.** 연령방 → 검사 선택 → 응시 → 결과. 실제로 작동하는 기능 | 🟢 실제 작동 |
| **강의·코칭** | 검사 이후 연결되는 강의·집단상담·부모교육·1:1 코칭 소개 | 🟡 예시 화면만 |
| **기관·단체** | 학교·기업·복지관 단체 도입 안내 + 문의 폼 | 🟡 화면만(문의 저장 X) |
| **리포트샘플** | 신호등 결과 리포트가 어떻게 나오는지 미리보기 | 🟡 예시 화면만 |
| **전문가·파트너** | 상담사·강사·코치 소개 + 전문가 연결 신청 | 🟡 예시 화면만 |
| **고객센터** | 자주 묻는 질문(FAQ) + 운영시간 안내 | 🟡 예시 화면만 |

우측에는 로그인 상태에 따라:
- 로그인 전 → **로그인 / 회원가입** 버튼
- 로그인 후 → **내 검사함**(내가 응시한 검사 이력·보유 검사권)

> **7개 탭 중 "심리검사"만 실제로 작동하는 기능**이고, 나머지 6개는 소개·안내용 화면입니다.
> (나머지 6개는 협의로 "이건 실제로 만들자"가 정해지면 하나씩 기능을 붙이면 됩니다.)

## 3. 연령별 '마음의 방'

검사를 **연령대로 묶은 방**입니다. "나는 지금 어느 방에 있나?"로 먼저 고르게 하는 구조.

| 방 | 대상 | 방에 들어갈 검사(예정) |
|---|---|---|
| **초등학생** | 부모·교사가 대신 응답 | 마음안전선별·정서행동·사회성·주의집중·스마트폰 |
| **중고등학생** | 학생 본인 | 청소년 마음상태·학업스트레스·시험불안·진로성향·대인관계 |
| **대학생** | 본인 | 우울·불안·스트레스·진로정체감·대인관계·자기조절 |
| **직장인·성인** | 본인 | 번아웃·직무스트레스·분노조절·회복탄력성 |
| **실버** | 본인·가족 | 실버 마음상태·우울고독감·인지건강·삶의만족도 |

> 방 구조 자체는 작동하지만, **위 검사 목록은 아직 "예정" 목록**입니다.
> 실제로 응시 가능한 검사가 들어 있는 방은 **직장인·대학생 방뿐**이고, 나머지 방은 지금 들어가면 비어 있습니다.

## 4. 검사 사용 흐름 (사용자가 겪는 순서)

```
  ①              ②            ③           ④          ⑤
연령방 선택 →  검사 선택  →  동의  →  문항 응시  →  신호등 결과
(어느 방?)    (어떤 검사?)  (개인정보)  (1~5점 답)   (초록/노랑/빨강 리포트)
                                                        │
                                                        ▼
                                              결과 기반 코칭 추천
```

1. **연령방 선택** — 홈이나 심리검사 탭에서 내 연령방 입장
2. **검사 선택** — 방 안에서 검사를 고름 (문항 수·소요시간·무료/유료 표시)
3. **동의** — 개인정보 동의 (아동검사는 보호자 동의도)
4. **응시** — 문항에 1~5점으로 답, 진행바로 진척 표시
5. **결과** — 영역별 **신호등(초록·노랑·빨강)** + 막대그래프 + 쉬운 해석문 + 맞춤 솔루션 추천

### 무료 / 유료 / 로그인 규칙

- **무료 검사** → 로그인 없이도 바로 응시 가능 (비회원도 결과·이력 확인됨)
- **유료 검사** → ①로그인 필요 → ②검사권 없으면 결제 → ③검사권으로 응시
- **아동(보호자 동의) 검사** → 응시 전 보호자 동의를 받아야 진행
  - ※ 지금은 실제로 켜진 아동검사가 없어 이 동의 절차가 화면에 나타나진 않음. 아동검사를 열 때 켜면 됩니다.

> **이 ①~⑤ 전체 흐름(고르기→동의→응시→신호등 결과)은 실제로 끝까지 작동합니다.**
> 비회원 응시, 유료 검사권 사용까지 포함해서요.

---

## 5. 결과 리포트 — 신호등 방식

- 전문용어 대신 **초록(양호) · 노랑(관심·조기지원) · 빨강(집중지원)** 신호등으로 표시
- **영역별 그래프**(예: 스트레스·우울·불안·회복탄력성)로 어디가 높은지 한눈에
- **쉬운 해석문** + 결과에 맞는 **강의·코칭 추천**으로 연결
- "리포트샘플" 탭에서 이 모습을 미리 볼 수 있음

---

## 6. 회원가입 · 로그인

- **회원 유형 2가지**: 개인 / 기관 (기관은 기관명 추가 입력)
- **카카오 간편 로그인** 지원
- 일반 이메일 가입, 비밀번호 찾기 등 기본 기능 포함
- 마케팅 수신 동의는 선택

> 회원가입·로그인은 실제로 작동합니다.

---

## 7. 결제 · 검사권

- 유료 검사는 **검사권(이용권)** 방식: 결제하면 검사권이 생기고, 유료 검사 응시할 때 검사권 1개 사용
- 검사권에는 수량·유효기간(예: 1년)이 있음
- **주문 → 결제 → 검사권 발급 → 검사 응시**까지 흐름이 만들어져 있음
- ※ 단, **실제 카드결제(PG사) 연동은 아직** — 지금은 테스트용 결제 버튼으로만 동작. 실제 오픈 시 결제사 연동 필요.

---

## 8. 관리자 페이지

- 회원 수·검사 수·주문 수·매출 통계, 최근 회원/주문, 검사별 응시 수를 볼 수 있는 관리자 화면 있음
- ※ **현재 로그인·권한 잠금이 없어** 정식 오픈 전 반드시 접근 보안 처리가 필요합니다.

## 10. 정리 — 되어 있는 것 / 아직인 것

**🟢 이미 작동하는 것 (엔진)**
- 검사 고르기 → 동의 → 응시 → 신호등 결과까지 전 과정
- 비회원 응시 + 내 검사함 이력
- 개인/기관 회원가입, 카카오 로그인
- 주문·검사권 발급·사용 흐름

**🟡 아직 샘플/화면만 (콘텐츠·포장)**
- 실제 검사 콘텐츠 (지금 2종 샘플뿐)
- 마음의 방 검사 라인업 (초등·중고등·실버 방 비어 있음)
- 강의·코칭, 기관·단체, 전문가, 소개, 고객센터 페이지 (소개 화면만)
- 실제 카드결제 연동
- 관리자 접근 보안

## 11. 협의에서 정하면 좋을 것

1. **어떤 검사부터 실제로 채울지** — 우선순위 (기관 주고객이면 어느 연령방/검사부터?)
2. **아동검사 보호자 동의 정책** — 아동검사 열 때 필수
3. **실제 결제 연동 시점** — 유료 검사를 실제로 팔 시점·결제사
4. **소개 페이지 6개 중 실제 기능화할 것** — 기관 문의 접수, 전문가 연결, 코칭 신청 등
5. **관리자 보안** — 정식 오픈 전 필수
6. **기존 단디 검사 콘텐츠를 심지로 어디까지 옮길지**
