# 심지(simji) 현재 사이트 — 협의용 정리

## 1. 사이트가 지향하는 것

**"마음을 검사하고, 삶을 코칭하다"** — 전 생애(초등생 ~ 실버 세대) 마음건강 플랫폼.

- 연령별 **'마음의 방'** 으로 나눠, 복잡한 검사 목록 대신 나에게 맞는 방부터 고름
- 결과는 전문용어 대신 **초록·노랑·빨강 신호등** 리포트로 쉽게
- 검사에서 끝나지 않고 **결과 이후 강의·코칭으로 연결**
- 개인뿐 아니라 **학교·기업·복지관 등 기관 단체 도입**을 주요 고객으로 → 기관이 **여러 명에게 검사를 뿌리고 결과를 모아 관리**하는 구조

---

## 2. 상단 메뉴(네브바) — 각 탭이 하는 일

| 탭 | 역할 | 현재 상태 |
|---|---|---|
| **심지소개** | 브랜드 스토리 — "검사 사이트를 넘어 마음성장 플랫폼" 소개 | 🟡 소개 화면만 |
| **심리검사** | **핵심.** 연령방 → 검사 선택 → (직접 응시 / 여러 명 발급) → 결과 | 🟢 기능 작동 |
| **강의·코칭** | 검사 이후 연결되는 강의·집단상담·부모교육·1:1 코칭 소개 | 🟡 예시 화면만 |
| **기관·단체** | 학교·기업·복지관 단체 도입 안내 + 문의 폼 | 🟡 예시 화면만 |
| **리포트샘플** | 신호등 결과 리포트가 어떻게 나오는지 미리보기 | 🟡 예시 화면만 |
| **전문가·파트너** | 상담사·강사·코치 소개 + 전문가 연결 신청 | 🟡 예시 화면만 |
| **고객센터** | 자주 묻는 질문(FAQ) + 운영시간 안내 | 🟡 예시 화면만 |

우측에는 로그인 상태에 따라:
- 로그인 전 → **로그인 / 회원가입** 버튼
- 로그인 후 → **내 검사함** (검사권 발급 결과·명부 관리 + 내가 응시한 이력)

---

## 3. 연령별 '마음의 방'

검사를 **연령대로 묶은 방**입니다. "나는 지금 어느 방에 있나?"로 먼저 고르게 하는 구조.

| 방 | 대상 | 방에 들어갈 검사 |
|---|---|---|
| **초등학생** | 부모·교사가 대신 응답 | 마음안전선별·정서행동·사회성·주의집중·스마트폰 |
| **중고등학생** | 학생 본인 | 청소년 마음상태·학업스트레스·시험불안·진로성향·대인관계 |
| **대학생** | 본인 | 우울·불안·스트레스·진로정체감·대인관계·자기조절 |
| **직장인·성인** | 본인 | 번아웃·직무스트레스·분노조절·회복탄력성 |
| **실버** | 본인·가족 | 실버 마음상태·우울고독감·인지건강·삶의만족도 |

## 4. 검사 상세 — 두 갈래로 이용 (직접 응시 / 여러 명 발급)

검사를 고르면 상세 화면에 **두 가지 이용 방법이 나란히** 뜹니다.

```
┌─────────────────────┬─────────────────────┐
│ 직접 응시하기         │ 여러 명에게 발급하기  │
│ 내가 바로 검사받고    │ 응시 링크를 만들어    │
│ 신호등 결과 확인      │ 여러 명에게 전달      │
│ [검사 시작]          │ [수량] [검사권 발급]  │
│                     │ [여러 명 한번에(엑셀)]│
└─────────────────────┴─────────────────────┘
```

- **직접 응시** — 본인이 검사를 받는 경우
- **여러 명에게 발급** — 기관/개인이 검사권을 만들어 다른 사람에게 링크로 보내는 경우

### 검사 사용 흐름 (직접 응시할 때)

```
연령방 선택 → 검사 선택 → 동의 → 문항 응시(1~5점) → 신호등 결과 → 코칭 추천
```

1. **동의** — 개인정보 동의 (아동검사는 보호자 동의도)
2. **응시** — 문항에 1~5점으로 답, 진행바로 진척 표시
3. **결과** — 영역별 **신호등(초록·노랑·빨강)** + 그래프 + 쉬운 해석문 + 맞춤 솔루션

### 로그인 규칙

- **직접 응시는 모두 로그인 필수** (무료·유료 구분 없이, 검사 시작 시 로그인 화면으로 안내)
- **발급받은 링크로 들어온 응시자는 로그인 불필요** — 5장 참고
- **아동(보호자 동의) 검사** → 응시 전 보호자 동의 필요

## 5. 검사권 발급 → 링크 전달 → 결과 관리 (기관 핵심 흐름)

기관이 여러 명에게 검사를 시키고 결과를 모아 보는, **단디(마음알지) 방식**을 심지에 구현.

### ① 발급 — 심리검사에서
검사 상세의 **"여러 명에게 발급하기"** 에서 **수량**을 정해 발급하면, 수량만큼 **고유 응시 링크**가 만들어집니다.
- 무료 검사는 바로 생성, 유료 검사는 보유 검사권에서 차감
- **대량 발급(엑셀)** — 이름·전화번호 명단을 엑셀로 올려 한 번에 발급하는 화면 (준비 중)

### ② 전달
발급하면 **내 검사함**의 명부에 뜨고, 각 건마다 **[링크 복사]** 로 카톡·메일 등에 붙여 전달합니다.

### ③ 응시 (링크 받은 사람)
링크를 열면 **로그인 없이** 바로 응시합니다. 응시자가 **이름·나이만 입력** → 문항 응시 → 제출 → 신호등 결과.

### ④ 결과 관리 (발급자)
**내 검사함 → [발급·결과 관리] 탭**의 명부에서:
- 발급한 검사권별 **대상자 · 응시 상태(미응시/완료) · 신호등 · 결과 보기 · 링크 복사**
- **열람 승인/대기 토글** — 발급자가 응시자 본인의 결과 공개 여부를 통제. '대기'면 응시자에겐 "결과 준비 중"으로 보임.

---

## 6. 결과 리포트 — 신호등 방식

- 전문용어 대신 **초록(양호) · 노랑(관심·조기지원) · 빨강(집중지원)** 신호등으로 표시
- **영역별 그래프**(예: 스트레스·우울·불안·회복탄력성)로 어디가 높은지 한눈에
- **쉬운 해석문** + 결과에 맞는 **강의·코칭 추천**으로 연결
- "리포트샘플" 탭에서 이 모습을 미리 볼 수 있음

---

## 7. 회원가입 · 로그인

- **회원 유형 2가지**: 개인 / 기관 (기관은 기관명 추가 입력)
- **카카오 간편 로그인** 지원
- 일반 이메일 가입, 비밀번호 찾기 등 기본 기능 포함
- 마케팅 수신 동의는 선택
- 발급·관리는 로그인한 회원이면 개인/기관 구분 없이 동일하게 이용

---

## 8. 검사권 · 결제 (모델 협의 필요)

- 검사는 **검사권(이용권) 차감** 방식 — 검사 1건 이용/발급에 검사권 1개 사용.
- **아직 정해야 할 것**:
  - 검사권을 어떻게 확보하는가 — **요금제(예: 25/50/100개 묶음)** 방식? 금액?
  - 검사권이 **검사별 전용**인지, **아무 검사나 쓰는 범용**인지 (단디는 범용 크레딧)
  - **실제 카드결제(PG) 연동** — 지금은 테스트용 결제로만 동작

---

## 9. 관리자 페이지

- 회원 수·검사 수·주문 수·매출 통계, 최근 회원/주문, 검사별 응시 수를 볼 수 있는 관리자 화면
- 로그인·권한 잠금은 정식 오픈 전 적용 필요

---

## 10. 정리 — 되어 있는 것 / 아직인 것

**🟢 이미 작동하는 것**
- 검사 고르기 → 동의 → 응시 → 신호등 결과까지 전 과정
- 검사권 발급 → 링크 전달 → 로그인 없이 응시 → 명부에서 결과 관리 + 열람 승인/대기
- 로그인 필수 응시 + 내 검사함(발급·결과 관리 / 내 응시 이력)
- 개인/기관 회원가입, 카카오 로그인

**🔴 아직 없는 것**
- 실제 검사 콘텐츠 (지금은 시연용 샘플 2개)
- 마음의 방 검사 라인업 (모든 방에 실제 검사 필요)

**🟡 화면·목업만 (정식 단계에 구현)**
- 대량 발급(엑셀 업로드)
- 문자/알림톡 자동 발송 (지금은 링크 복사로 대체)
- 검사권 확보 방식(요금제)·실제 카드결제 연동
- 강의·코칭, 기관·단체, 전문가, 소개, 고객센터 페이지
- 관리자 접근 보안

---

## 11. 협의에서 정하면 좋을 것

1. **실제 검사를 넣는 작업(최우선)** — 어떤 검사부터 정식 문항·채점표로 채울지
2. **검사권·요금제 모델** — 확보 방식(묶음 요금제)·금액, 범용/검사별, PG 연동 시점
3. **대량 발급 + 문자 발송** — 엑셀 명단 업로드·일괄 문자/알림톡 발송 시점
4. **아동검사 보호자 동의 정책** — 아동검사 열 때 필수
5. **소개 페이지 6개 중 실제 기능화할 것** — 기관 문의 접수, 전문가 연결, 코칭 신청 등
6. **관리자 보안** — 정식 오픈 전 필수
7. **기존 단디 검사 콘텐츠를 심지로 어디까지 옮길지**
