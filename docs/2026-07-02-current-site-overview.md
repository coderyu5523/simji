# 심지(simji) — 협의용 정리

무엇이 어떻게 돌아가는지(검사 흐름)와, **각 메뉴·검사에 어떤 정보·자료·결정이 필요한지**를 협의하기 위한 문서.

---

## 1. 사이트 지향

**"마음을 검사하고, 삶을 코칭하다"** — 전 생애(초등생 ~ 실버) 마음건강 플랫폼.
- 연령별 **'마음의 방'** 으로 나눠 나에게 맞는 방부터 고름
- 검사 결과 → **강의·코칭으로 연결**
- **기관(학교·기업·복지관)** 이 주요 고객 → 여러 명에게 검사를 뿌리고 결과를 모아 관리

---

## 2. 검사 전반 흐름

### 검사 상세에서 두 갈래로 이용
```
┌─────────────────────┬─────────────────────┐
│ 직접 응시하기         │ 여러 명에게 발급하기  │
│ 내가 바로 검사받고    │ 응시 링크를 만들어    │
│ 결과 확인            │ 여러 명에게 전달      │
└─────────────────────┴─────────────────────┘
```

### ① 직접 응시 (개인)
```
연령방 선택 → 검사 선택 → 동의 → 문항 응시 → 결과 → 코칭 추천
```
- 직접 응시는 **로그인 필수**, 아동검사는 **보호자 동의** 후 진행

### ② 발급 → 전달 → 관리 (기관 핵심)
```
검사권 발급(수량/엑셀) → 링크 전달 → [받은 사람] 로그인 없이 응시 → [발급자] 명부에서 결과 관리
```
- 발급자가 검사권을 링크로 만들어 전달 → 받은 사람은 이름·나이만 넣고 응시
- 발급자는 **명부**에서 대상자·응시상태·결과를 모아 보고, **결과 열람 승인/대기**를 통제
- ※ 지금은 링크 복사로 전달. 명단 엑셀 업로드·문자 발송은 정식 단계.

---

## 3. 연령별 '마음의 방'

| 방 | 대상 | 방에 들어갈 검사 |
|---|---|---|
| **초등학생** | 부모·교사가 대신 응답 | 마음안전선별·정서행동·사회성·주의집중·스마트폰 |
| **중고등학생** | 학생 본인 | 청소년 마음상태·학업스트레스·시험불안·진로성향·대인관계 |
| **대학생** | 본인 | 우울·불안·스트레스·진로정체감·대인관계·자기조절 |
| **직장인·성인** | 본인 | 번아웃·직무스트레스·분노조절·회복탄력성 |
| **실버** | 본인·가족 | 실버 마음상태·우울고독감·인지건강·삶의만족도 |

→ 라인업은 기획안 기준 예정 목록. **실제 검사 확정·순서**는 협의 필요.

---

## 4. 메뉴별 — 필요한 정보·자료 (협의)

각 메뉴에서 **현업에서 받아야 하거나 정해야 하는 것**입니다.

| 메뉴 | 역할 | 필요한 정보·자료 |
|---|---|---|
| **심지소개** | 브랜드 소개 | 회사 소개문·연혁, **로고·파비콘**, 대표 이미지 |
| **심리검사** | 핵심 검사 기능 | **검사 문항·채점 규준·결과 구성**(→ 5장), 소개 문구·이미지 |
| **강의·코칭** | 프로그램 소개 | 프로그램 목록·소개문·이미지, 신청/문의 받는 방식 |
| **기관·단체** | 단체 도입 안내 | 도입 안내문·혜택, **문의 접수·처리 방식**(누가 어떻게 받나) |
| **리포트샘플** | 결과 미리보기 | **실제 샘플 리포트**(신호등+그래프·해석 예시) |
| **전문가·파트너** | 전문가 소개 | **전문가 프로필·사진**, 연결/매칭 방식 |
| **고객센터** | FAQ·연락 | FAQ 내용, **대표전화·운영시간·카카오채널·이메일** |

---

## 5. 검사에 필요한 정보 (핵심)

검사 정보를 현업에서 받으면 아래를 넣어 완성합니다.

- **문항** — 실제 문항, 척도(몇 점), 역채점 여부
- **채점 규준표** — 원점수 → **T점수·백분위** 변환, 하위척도·**종합지수**, 신호등 단계 기준
- **결과 표현** — **신호등 요약 + 정밀 프로파일**(영역별 점수·그래프·해석문·PDF) 둘 다
- **대상 규칙** — 대상 연령, **보고자(부모/교사/성인)**, 월령에 따른 분기
- **검사 소개** — 검사 설명 문구, 소개 이미지
- **라인업** — 방별 실제 검사 종류·순서 확정

---

## 6. 정해야 할 운영 정책

- **검사권·요금제** — 검사권 확보 방식(묶음 요금제)·가격, 범용/검사별, 유효기간
- **결제(PG)** — 실제 카드결제 붙일 시점·결제사
- **문자/알림톡 발송** — 발송 문구, 발신번호(사업자 명의)·카카오 채널 개설
- **아동검사 보호자 동의** — 어떤 검사에 필수로 걸지
- **회사·법적 정보**(유료 판매 필수) — 사업자등록번호·통신판매업 신고·이용약관·개인정보처리방침·환불규정
